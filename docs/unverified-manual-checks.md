# 未验证的手工检查项

本文件是 ZeroSlack **至今没有在真机桌面上手工验证过的检查项**的唯一清单，不是验收史。
每一项都记录三件事：**待执行步骤**、**自动化已覆盖到什么程度**、**自动化覆盖不到的缺口**。

2026-09-21：用户授权正式包默认启用 SuiteUi。该发布决定不将下列未验项改记为通过；
SDK 的后台回归和部分原生操作证据继续按各自范围解释。

两条一直适用的纪律：

- offscreen 与自动化结果**不能**当作真机验证。自动化通过只说明被测逻辑成立，不说明桌面观感、
  原生手势、窗口管理器时序或多显示器行为成立。
- 至今没有生成过冒充手工验收的截图。截图空缺就是空缺。

截图目录（有 `build/` 前缀的均为本机忽略目录）：`build/evidence/`。

## 1. 原生窗口外框（frameMargins）真机测量

**待执行**：记录 Windows 上 `show()` 前后的 frameMargins 上/下/左/右四边实测数字；保存外框
x/y/width/height；连续重启并重新打开两次，逐字段比较每次外框。

**自动化覆盖**：几何捕获与纯函数换算；`setView` 返回时的外框不变量；生产序列化往返。
show 后先保留请求几何、再重新应用、之后才记录外框的自纠正逻辑已落地。

**缺口**：没有任何真机四边数值。构造时 `winId` 创建句柄不等于边框尺寸已有效。若 show 前为 0、
show 后才非零，`applyGeometry` 可能把外框当成客户区，`rememberGeometry` 再保存偏大的外框，
重启可能逐次漂移。offscreen 无法排除该风险，也不足以据此改动原生窗口实现。**属遗留风险。**

## 2. 多显示器与跨屏拖动

**待执行**：把浮起的 RTL Insight 拖到副屏并调整大小；三个窗口移到不同坐标/显示器后收起再展开，
逐个比较外框；在副屏保存几何后断开副屏，重启再打开。

**自动化覆盖**：三个 native Tool 对象、cascade 放置、隐藏/恢复全字段、几何捕获；纯函数覆盖
屏幕缺失时的完全回落。

**缺口**：未覆盖 Windows 原生拖动、混合 DPI 切换，以及系统显示器移除事件的实际时序。
offscreen 屏幕名为空，依赖屏幕名的分支在集成测试里走不到（已知覆盖盲区）。

## 3. 连续重启后的几何与布局对照

**待执行**：记录三次启动的 x/y/w/h 与 frameMargins；三个 section 同时显示，折叠、改高、重排后
重启对照；浮层窗口调整位置后重启重新打开。

**自动化覆盖**：精确几何恢复、生产序列化往返、v5/v6 状态读写。

**缺口**：未覆盖真实的连续进程重启与 Windows 原生边框时序。

## 4. 侧栏竖栈手感与拖出／拖回手势

**待执行**：三个 section 同时显示时的观感；标题条拖出成浮层，再用客户区手柄拖回指定插入线。

**自动化覆盖**：真实鼠标事件、几何与信号、生产拖回处理器、三种落点、同视图身份、取消状态。

**已缩小的缺口（2026-09-20）**：Qlementine 独立产品预览完成单个 Kernel section
拖出、标题移动及 Pin 返回；后续安装版 SuiteUi 0.1.1 的独立原生程序再次完成 Kernel
拖出、Block/Hotspot 浮动、Hotspot 标题移动和 Pin 返回。三个 section 的连续重排、
拖回指定插入线及手感仍未验证；Pin 返回不抵作指定落点拖放。

## 5. 文档绑定的真实标签交互

**待执行**：给文档 A 建绑定窗口，切到 B 再切回 A；A 的两个绑定窗口调整位置后关闭 A 再重开。

**自动化覆盖**：路径通知后的可见性、同资源同视图、精确几何；`documentClosed` 释放 QWidget、
布局归档、重开恢复两个实例及 Kept 计数。

**缺口**：未覆盖实际用鼠标点击标签切换与关闭／重开的全过程。

## 6. 临时编辑器（Peek）逐项对照

**待执行**：对照上一版本，逐项操作 Peek 的打开、缩放、Pin、Unpin 与共享文档编辑。

**自动化覆盖**：原 overlay 测试、共享视图搬运、真实 provider 不可分离、provider 与搜索、窄宽度审计。

**缺口**：未测真实输入法/焦点观感与键鼠操作手感。

## 7. 浮层材质的系统回退与真实图表

**待执行**：切换系统透明效果、高对比度和节电状态，确认原生浮窗实时回退为实色背景。
对真实图表浮窗执行 Pin/Unpin，确认材质不影响内容与交互。

**自动化覆盖**：全局偏好存储与滑块即时更新；焦点变化不降低整窗透明度；不支持材质的平台
绘制不透明主题背景；主题切换保持原生窗口标识、几何和窗口标志。
新增双色背景像素检查覆盖标题、搜索框、列表、表格、文本预览、滚动内容及图表空白区域，
验证浅色／深色／Catppuccin 主题、延迟创建内容、移回普通容器后恢复实色，以及节点和选中高亮保留。

**缺口**：系统状态切换以及带多节点真实图表的完整材质验收尚未在原生桌面完成。
2026-09-20 Qlementine 产品预览完成单节点 Kernel 的侧栏拖出和 Pin 返回，内容保持可见；
该操作不替代系统回退、材质浓度和多类复杂图表的验证。
独立的 `context_floating_preview` 已经通过 Windows 桌面工具检查浅色／深色材质、背景浓度、
标题栏拖动、右边框缩放与失焦后的文字显示；这些结果不替代本项剩余检查。
预览程序已补充带数据的热点轨道／矩阵、果核图和文档控件。本轮完成后台离屏回归，
整窗材质与真实图表 Pin/Unpin 的桌面视觉验收仍待执行。

## 8. Context Rail 逐 provider 手工点击

**待执行**：逐一点击每个真实 provider 的 rail 入口，验证打开、收起与复用。

**自动化覆盖**：mock 与 Pinloom 的打开/收起/复用，并回归 liveInsights 与 RTL workbench。

**缺口**：不等同于逐一点击所有真实 provider。

## 9. Pin/Unpin 保留滚动位置与撤销

**待执行**：在有滚动位置和撤销历史的内容上执行 Pin 与 Unpin，检查两者是否原样保留。

**自动化覆盖**：pin/unpin 移动的是同一个 QWidget、共享同一 QTextDocument，已有共享编辑内容保留。

**缺口**：未手工验证滚动值与撤销操作。

## 10. 旧工作区状态的真机迁移

**待执行**：用旧版本保存三资源并记住活动项，再用当前版本启动观察迁移结果。

**自动化覆盖**：实际用旧 EXE 的输出导入成功；构造的 v5 三资源迁移后只展开原活动项。

**缺口**：未以原生桌面完整启动观察旧工作区的迁移过程。

## 11. 语义可用性：注释后恢复与 F12 跳转

**待执行**：打开已完成分析的工程，在某个信号声明上方插入一行注释和空行，**不保存**；暂停后检查
RTL Insights 右键项恢复可用；在引用处按 `F12`，确认跳到编辑后的实际声明行。
截图：`build/evidence/edit-idle-review/trivia-current-and-definition.png`。

**自动化覆盖**：`runEditIdleActionAvailabilityFollowsPublishedState` 验证了 Current 状态、
F12 对应 action 可执行，以及声明行列正确。

**缺口**：未在真机上实际按下 F12 跳转。

## 12. 语义可用性：重命名后置灰

**待执行**：在同一文件重命名信号但**不保存**；暂停后检查语义项仍不可执行，悬停文案仍为
`Semantic snapshot is stale; analyze the workspace.`。
截图：`build/evidence/edit-idle-review/identifier-stale.png`。

**自动化覆盖**：服务测试确认 Stale 状态、F12 不可执行、右键语义项提示仍为原文。

**缺口**：未在真机上操作。

> 补充执行说明（来自原 edit-idle 手工复核步骤）：若另一分析任务尚在运行，等任务结束后再追加一个

## 13. A1 按钮与复选框的桌面观感

**待执行**：六种主题下检查设置页 Apply/Revert、普通复选框和 Kernel 筛选；使用鼠标与
Tab/Shift+Tab、Space 连续操作；将 Kernel 浮起、停靠并跨不同 DPI 屏幕，核对勾选标记、
焦点描边、禁用状态与文字间距。A1 使用即时状态反馈，没有新增动画。

**自动化覆盖**：六主题、四档缩放的实际控件输入、取消点击、禁用/隐藏中断、尺寸稳定、
主窗口设置入口、同一 Kernel 面板在实际浮窗组件与停靠容器之间重挂载。

**缺口**：上述结果来自 offscreen；未覆盖 Windows 合成背景上的实际对比度、跨屏字体栅格化
与操作手感。实现及证据入口见 [A1 记录](control-style-consolidation.md)。

**A/C 后续对照**：独立 Qlementine 实验已补齐完整主窗口、实际浮窗组件、主题往返、
Hub 选中态与动画开关矩阵。C 适配器保留原生控件输入，并有一个动画清理的上游实现补丁；
该补丁的检查版复现和修复验证已单独保留。C 尚未进入产品默认路径，原生观感与帧节奏
仍需独立验收；离屏通过不能替代上述手工项目。

**可选产品预览补充（2026-09-20）**：原生 Windows 已检查浅色/深色界面、设置主题下拉框、
覆盖开关、Tab/Space、Revert、文件树打开编辑器，以及 Kernel 拖出/移动/固定返回。
发现并修复预览读取正式配置、品牌图标被统一重着色、深色禁用文字/勾选标记同色三项问题；
重建后重新启动确认配置隔离及禁用控件显示。其余四种主题、跨屏 DPI、DWM 帧节奏、
全部自定义字体与多窗口连续拖放仍待原生验收。详见 [产品试点记录](control-style-consolidation.md)。

**第二应用原型补充（2026-09-20）**：RegMap 临时项目已在原生 Windows 执行双行选择、
批量编辑中的 Space/Tab/Down、取消、Saved/原数据保持及 View→Dark 主题切换。
Light/Dark、四档缩放与动画开关的 24 组通过结果来自 offscreen；没有完成 RegMap 的
原生四档 DPI、跨屏或 DWM 帧节奏验收。它不抵销上述 ZeroSlack 的剩余原生项目。
原型、测试驱动修正与提取范围见 [第 3 阶段记录](suite.md#suiteui-第-3-阶段双应用验证与提取结论)。

**SuiteUi SDK 补充（2026-09-20）**：第 4 阶段把 C1/C2 收敛为独立的控件绘制 SDK，
ZeroSlack 与 RegMap 已进行独立构建、实际操作回归和离屏矩阵验证。仅保留系统 PATH 的
Windows `--version` 启动证明部署依赖可加载，不属于原生交互验收；第 3 阶段的桌面记录
也不能直接作为新 SDK 构建的桌面验收。上述原生 DPI、跨屏、Snap 和 DWM 项目仍待执行，
正式包默认样式未改变。详见 [第 4 阶段记录](suite.md#suiteui-第-4-阶段独立-sdk-与双应用接入)。

**SDK 0.1.1 收尾复核（2026-09-20）**：本次重新使用安装版 SDK 构建的独立原生程序，
不沿用上轮原型结论。ZeroSlack 同一设置页的 Light/Dark/四个 Catppuccin 主题均已截图；
这六主题静态对照不再列为未验。键盘左右半屏和四角贴靠的 DWM 实际矩形分别为
1920×2088、1920×1044，工作区为 3840×2088；还原为原先的 1200×900。
Win32 同时测得窗口 DPI 144、系统缩放 150%，不使用陈旧的注册表值推定缩放。
RegMap 原生 Light/Dark 已截图，左右半屏、左上角和还原有几何证据；它没有另外四个主题。

Kernel 拖出、Block/Hotspot 浮动、Hotspot 标题移动和 Pin 返回有原生输入/截图记录；
没有完成三面板连续重排并拖回指定插入线。边缘缩放尝试未得到可确认几何变化，仍未验。
窗口工具只返回主窗口并限制拖动端点范围，不能以 Pin 返回代替精确拖放验收。RegMap
当前为固定 splitter 布局，没有同样的三 section 自由停靠入口，本轮未增加该功能。

剩余缺口：鼠标拖到屏幕边缘的 Snap；RegMap 其余角落与连续按键（尝试出现最小化，
尚未排除宿主激活/系统行为，不能判定已通过）；100/125/200% 真正系统 DPI（启动系统
设置的工具授权等待超时，未改变设置）；第二屏/断屏（只有一台实际显示器）；有效 DWM
帧节奏（WPR 普通及宿主调用均返回 0x80070005；只读 API 的 18,810 次采样中
qpcFrameDisplayed 均为 0，不将 qpcVBlank 或抓图时间替作显示时间戳）。

上述工具、硬件和证据限制不记为已确认产品缺陷，也不构成这些场景正确的证据。
原始日志与逐项结论见 `build/evidence/plan-remainder-20260920/native/` 及该目录上级的
`report.md`。其余 §§1–12 的待验条目继续保留。
