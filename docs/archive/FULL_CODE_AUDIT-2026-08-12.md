## 审计方法

1. 完整覆盖 Editor、DocumentModel、Tab、AnalysisScheduler、SemanticIndex、Slang、TSDocument、Completion、命令模式、Navigation、Definition、References、Relationships、EffectiveValue、Ghost、Hover、Diagnostics、Workspace/Session/Cache、Hierarchy、FSM、Signal Kernel、Module Block、Wave Preview、Hotspot、各 panel/coordinator/service 和全部测试目标。
2. 搜索并阅读 `QRegularExpression`、字符串查找/切分、逐行与括号扫描、`toPlainText()`、全符号/全关系查询、全树/全文遍历、完整模型重建、`markContentsDirty`、timer/debounce、`processEvents`、重复 connect、UI 直接语义访问、路径与位置转换调用链。
3. 对确认缺陷先增加可暴露旧行为的回归测试或源码守卫，再替换生产实现；删除旧事实源、旧 fallback 和无调用入口，不保留并行逻辑。
4. 对合理保留项记录能力边界，避免机械删除命令解析、搜索过滤、日志与简单格式校验所需正则。

## 合理保留与能力边界

- 当前生产正则仅剩 3 个文件：`editorcompletionworkflow.cpp` 的空白分词、`editorcoordinator.cpp` 的命令首词切分、`foldblockshelfmodel.cpp` 的搜索分词和内部 ID 格式校验。它们不判断 SystemVerilog 语法或语义。源码策略白名单已收紧到这 3 个文件。
- 当前编辑缓冲区的 module/scope、折叠、高亮、结构选择和增量 changed ranges 已由 `TSDocument` / Tree-sitter 与 `QTextDocument::contentsChange` 驱动。此次没有确认出需要新增第二套 Tree-sitter 替换的缺陷，因此 Tree-sitter 新迁移数为 0；不为凑数量改写已经正确的路径。
- 编辑输入普通路径使用 cached semantic revision text 和 UTF-16 changed range，不在每次按键调用 `toPlainText()`。数字 hover 已改为单个 QTextBlock；剩余 `toPlainText()` 位于显式格式化、重命名、保存或用户命令边界，未确认是输入/光标/hover/滚动热路径缺陷。
- 用户显式打开的全工程报告仍允许读取完整 snapshot；被动语义刷新中的 Ghost、completion 和 panel 空态全记录复制已按 ZS-AUD-015、019、022 删除。
- 剩余 `QTimer::singleShot` 用于选择闪烁、queued drill-down 和 resize presentation，不承担语义计算或掩盖全量分析。
- UTF-16 Qt offset、Tree-sitter UTF-16LE byte offset、Slang UTF-8 line/column、CRLF 映射沿现有 `TSDocument` / source mapper 调用链复核；现有 Unicode/CRLF 回归保持覆盖，未确认新缺陷。
