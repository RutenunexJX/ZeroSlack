# Editor backgrounds

Built-in raster assets generated for ZeroSlack with the built-in image generation tool on 2026-09-22.
The original generated files remain outside the repository; these are unchanged copies of the selected results.

| Resource | Setting | Selected artwork |
| --- | --- | --- |
| `resting.png` | Resting (default) | Pale blue character resting on a lavender cushion; the marked small facial dot was removed. |
| `peekaboo.png` | Peekaboo | A / 偷偷探头: blue and cream characters peeking from the right. |
| `balancing.png` | Balancing | C / 差一点就倒: blue, cream and lavender forms in an unstable stack. |

Images preserve their original aspect ratio and blank space. Rendering fits the full image into the editor
viewport and anchors it at the bottom right. Opacity and theme tint are applied at runtime, below source text.
