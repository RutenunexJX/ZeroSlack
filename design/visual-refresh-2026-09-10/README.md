## 实施约束

保持现有功能，不依据生成图添加功能。左侧栏仅工程、设置；右侧上下文全高；无常驻状态栏；标题栏固定显示并占独立高度。圆角 8–12 px，图标 20–24 px，圆头圆角线条约 1.75 px，统一主题着色。界面字体使用比例字体，代码用等宽字体。浅色代码关键字应降低概念图中过强的纯蓝饱和度并检验对比度。

生成图中的代码、诊断、文字和属性仅为示意；图标板中 Run Project、Main Branch、快捷键、宣传文字不构成功能需求。行号区仍按标记／行号／折叠／代码排列，Pinloom 与诊断共用标记区，不按图中示意另加链接列。四主题比较图的底栏跨度不作为布局依据。
